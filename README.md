# Aromas de Puerto Rico — post media

Public image host for @aromasdepr Instagram posts.

**This repo exists for one technical reason:** Instagram's Content Publishing
API does not accept an upload. It fetches the image itself from a public HTTPS
URL, so finished posts have to be reachable on the open web before they can be
published.

Images here are finished marketing assets that are going onto a public
Instagram account anyway. Nothing private, no source files, no customer data.

Files are pushed by `company/aromas/marketing/studio/scripts/upload-media.mjs`
in the main workspace. Do not edit by hand.
